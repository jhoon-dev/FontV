# Font V 실기기 심사 영상 안내

준비일: 2026-11-09 (한국 시간). Apple ID `6831850547`, Bundle ID `app.toolmoa.fontv`.

## 확인된 Apple 요청

11월 9일 오전 11:34 Apple 메시지는 **Guideline 2.1 - Information Needed - New App Submission**이다. 앱 실행부터 일반적인 사용 흐름을 보여주는 **최신 OS의 실물 기기 화면 기록**, 실기기 QA, 그리고 목적·대상, 사용 방법, 외부 서비스, 지역 차이, 규제·보호 자료에 대한 설명을 요구했다. 버그나 크래시의 구체적인 재현 사례를 지적한 메시지는 아니다.

현재 거절된 제출은 **2.0.0 (9)**다. 새 기능과 공통 헤더가 포함된 **TestFlight 2.0.0 (11)**로 촬영·실기기 QA를 진행하고, 완료 후 같은 빌드를 재제출 대상으로 선택한다. 이 문서 작성 시 App Store 제출 빌드는 변경하지 않았다. 11을 사용할 수 없으면 촬영 전에 실제 설치 빌드부터 확인한다. 빌드를 바꾸면 영상·메모·제출 빌드도 함께 맞춘다.

## 촬영 전

1. 실물 iPhone/iPad를 최신 호환 정식 OS로 업데이트하고 TestFlight에서 Font V **2.0.0 (11)**을 설치한다. TestFlight 상세에서 버전·빌드 번호를 확인한다.
2. 기기 모델, 정확한 iOS/iPadOS 버전, 빌드, 날짜를 `physical-device-results.csv`에 기록한다. 알림에 개인 정보가 나오지 않게 정리한다.
3. 개인 자료 대신 샘플 문장 `Hello Font V / 안녕하세요 / 12345`와 컬렉션 이름 `Review fonts`를 사용한다. 파일 가져오기를 시연하려면 본인이 사용할 권리가 있는 TTF/OTF 한 개를 파일 앱에 준비한다. 기본 탐색에 샘플 파일은 필요하지 않다.
4. 제어 센터의 **화면 기록**을 켜고 홈 화면으로 돌아온 뒤 Font V 아이콘을 눌러 시작한다. 화면 기록은 사진 앱에 저장된다. 음성 설명은 필수가 아니다.

## 권장 촬영 순서

권장 길이는 3–5분이며 Apple의 길이 제한은 아니다. 다음 동작을 읽을 수 있는 속도로 보여준다.

| 순서 | 조작 | 보여줄 결과 |
| --- | --- | --- |
| 1 | 홈 화면에서 Font V 실행 | 로그인 없이 실제 기기 폰트 목록 표시 |
| 2 | 폰트 패밀리 펼치기·접기, 오른쪽 문자 인덱스 탭, 이름 검색 | 패밀리·스타일 구분과 빠른 탐색 |
| 3 | 서체 열기 → 직접 입력 → 샘플 문장 적용 → 크기·글자색·배경색 변경 | 실제 서체 미리보기·입력·키보드 동작 |
| 4 | 미리보기 옵션에서 자간·행간·정렬 변경, 문자 지원 확인 | 변경 결과와 지원/누락 문자 설명 |
| 5 | 북마크로 즐겨찾기 추가 → 즐겨찾기 탭 확인 | 저장한 서체 표시 |
| 6 | 목록 상단 비교 버튼 → 서로 다른 서체 두 개 선택 → 비교 | 같은 문장의 나란한 비교 |
| 7 | 컬렉션 생성 `Review fonts` → 서체를 컬렉션에 추가 → 컬렉션 열기 | 이름 있는 폰트 묶음 |
| 8 | 서체 상세에서 저장·공유 화면 → PNG 미리보기 → 파일에 저장 → 공유 시트 열었다 닫기 | 실제 PNG 내보내기와 iOS 파일·공유 화면 |
| 9 | 파일 가져오기 → 준비한 TTF/OTF 선택 → 가져온 서체 열기 | 앱 내부 파일 복사·미리보기. 원본은 유지 |
| 10 | 설정 → 테마 변경, English/한국어 전환, 개인정보처리방침 열기 | 같은 굵기·색상의 Font V 헤더, 언어·지원 안내 |
| 11 | 홈 화면 → 앱 전환기에서 종료 → 다시 실행 → 즐겨찾기·컬렉션 확인 | 저장한 설정·자료 복원 |

기능이 실패하면 성공한 것처럼 편집하지 않고 결과표에 재현 순서를 기록한다. 광고는 검토 상태·지역·동의·네트워크에 따라 없을 수 있다. 실광고를 클릭하거나 광고를 억지로 노출시키지 않는다. 폰트 탐색은 광고 유무와 관계없이 동작해야 한다.

## iPad와 추가 QA

Apple은 지원하는 각 기기 플랫폼에서 QA를 요구했지만 **iPhone·iPad 각각의 별도 전체 영상 두 개를 명시하지는 않았다**. iPhone 전체 영상과 iPad 주요 흐름 영상을 권장한다. iPad에서는 목록·상세 표시, 세로·가로 회전, 키보드, 파일 선택기, PNG 저장, 공유 팝오버, 재실행 복원을 확인한다. 없는 기기의 결과를 완료로 기록하지 않는다.

실기기에서 작은 화면·큰 시스템 글자, 뒤로 가기, 백그라운드 복귀, 오프라인 폰트 탐색, 설정 복원도 확인한다. 기존 자동화의 iOS 시뮬레이터 통합 테스트는 실기기 QA와 구분한다.

## 전달 및 재제출

영상 파일명 예: `FontV-iPhone-2.0.0-11-20261109.mov`. 기기가 생성한 `.mp4`도 그대로 사용할 수 있다. 영상과 함께 기기 모델·정확한 OS·빌드·테스트 날짜·성공/실패 결과를 전달한다.

영상은 실제 실물 기기의 원본 화면 기록이어야 한다. 현재 개발 환경에는 연결된 iPhone/iPad 녹화 기능이 없어 사용자 촬영이 필요하다. Windows 화면이나 시뮬레이터 영상으로 대신하지 않는다.

영상과 실제 QA 결과를 받은 뒤 `ios-review-notes.txt`의 `[PENDING]`을 채운다. App Review Information의 Notes에 여섯 항목을 모두 넣고, 지원되는 첨부 방식 또는 심사자가 로그인·접근 승인 없이 볼 수 있는 영상 링크를 제공한다. 실제 재생을 확인하고 제출 빌드를 11로 맞춘 뒤 다시 제출한다. 미완료 초안이나 실기기 테스트를 했다는 허위 진술을 제출하지 않는다.
