Font V는 Windows PC에 설치된 글꼴을 탐색하는 오프라인 폰트 도구입니다. 원하는 문장으로 서체를 미리 보고 다음 디자인에 어울리는 글꼴을 찾아보세요.

• 폰트 패밀리·스타일 검색과 오른쪽 문자 인덱스
• 같은 문장과 설정으로 2–4개 서체 비교
• 글자 크기·자간·행간·정렬·글자색·배경색 조절
• 문자 지원 검사와 현대 한글 완성형 지원 글꼴 필터
• 즐겨찾기와 이름 있는 컬렉션
• 폰트 정보와 투명 배경을 선택할 수 있는 PNG 내보내기
• 시스템에 설치하지 않고 앱 내부에 TTF/OTF 파일 가져오기
• 한국어·영어 UI와 다섯 가지 색상 테마

폰트 목록, 가져온 글꼴, 입력 문장, 즐겨찾기와 설정은 기기에 저장됩니다. Windows 버전에는 광고, 계정 가입, 앱 내 구매가 없습니다. 표시되는 글꼴은 PC에 설치된 글꼴에 따라 달라집니다. 가져온 글꼴은 Font V가 배포하거나 사용권을 제공하는 것이 아니므로 각 글꼴의 라이선스를 따라 사용하세요.

Windows 10 버전 1809 이상, x64가 필요합니다.
